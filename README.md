# This or That Home

A phone-first "This or That" house design filter by Max Weberman. Enter size, bedrooms, bathrooms, and notes, answer 20 photo pairs, and get a style concept, room program, SVG block plan, material palette, mood board, and a rough price breakdown by region and finish tier.

Static site (vanilla JS). Photos are openly licensed from Wikimedia Commons and Openverse; credits are listed in the app (#credits). Cost sources are listed in the app (#sources). Estimates are rough, not quotes.
